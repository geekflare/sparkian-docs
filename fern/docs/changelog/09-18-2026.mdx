## Use a generated image as a reference

You can now take any image Sparkian generates and use it as a reference for your next generation — describe the change you want (a different color, pose, or detail) and Sparkian generates a new image based on it, instead of starting from scratch.

See [Creating images](/create-image) for how it works.

## Python for data analysis and charts

Sparkian now detects when a question needs real calculation — analyzing a spreadsheet, computing statistics, plotting a trend — and runs Python behind the scenes to answer it, showing the code it ran alongside the result and any charts it generates. Works with CSV, Excel, or data pasted directly into a message.

See [Data analysis and charts](/data-analysis) for how it works.
