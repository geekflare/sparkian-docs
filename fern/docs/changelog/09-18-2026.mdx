## Use a generated image as a reference

You can now take any image Sparkian generates and use it as a reference for your next generation — describe the change you want (a different color, pose, or detail) and Sparkian generates a new image based on it, instead of starting from scratch.

See [Creating images](/create-image) for how it works.
