## Context modes: Smart and Exact

Chat settings now include a **Context mode** option alongside Recent messages. **Smart** (default) summarizes older messages, which can use fewer Sparks in long chats. **Exact** sends only your selected recent messages, exactly as written, with no summarizing. Change it anytime for the current conversation in **Chat settings**.

See [Memory and context](/memory-and-context) for how it works.

## Personal memory

Sparkian can now remember useful details about you — your role, preferences, how you like answers formatted — across your private chats in a workspace, so you don't have to repeat yourself in every new conversation. Turn it on or off, and manage what's saved, from **Settings → General → Memory**.

See [Personal memory](/personal-memory) for details.
