Click **Search** in the sidebar, or press **⌘K** (Ctrl+K on Windows/Linux), to search across all your chats by title.

<Frame caption="Search chats">
  <img src="https://cdn.sparkian.com/docs/search-chats.png" alt="Search chats dialog"/>
</Frame>

## Filters

Narrow results with **Filters**:

- **Access** — Private and project / Private only / Project only
- **Conversation type** — All conversations / Original conversations / Branches only
- **Activity** — Any time, or a recent time window
