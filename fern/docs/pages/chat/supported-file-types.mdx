You can attach files to any chat by dragging and dropping them into the message box or using the attachment icon. Sparkian processes attachments for analysis, data extraction, and visual understanding, depending on the model you're chatting with.

## Documents and presentations

- PDF
- Word (`.docx`)
- PowerPoint (`.pptx`)
- Plain text (`.txt`)
- Markdown (`.md`)

## Spreadsheets and data

- Excel (`.xlsx`)
- CSV

## Code and web files

- Config files — JSON, YAML, INI
- Web markup — HTML, CSS
- Code files — Python, JavaScript, TypeScript

## Images

- JPG, PNG, WebP
- SVG (vector graphics)

## Token usage from attachments

Attaching files increases the total token count of your prompt — larger or multiple files mean more tokens. If your request goes over the base token allowance, Spark cost multipliers apply. See [Sparks (credit system)](/sparks) for more details.
