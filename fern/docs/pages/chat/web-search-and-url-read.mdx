Models don't know about anything after their training cutoff, and can't see a specific page you're talking about unless you give it to them. Sparkian has two tools for that.

<Frame caption="Add tools and actions menu">
  <img src="https://cdn.sparkian.com/docs/chat-tools-menu.png" alt="Add tools and actions menu"/>
</Frame>

## Web search

Turns on live web search for the conversation, so responses can pull in current information instead of relying only on the model's training data. Toggle it from the **+** (Add tools and actions) menu, or type `/search` in the message box.

## URL read

Fetches and reads the content of a URL you share, so the model can answer questions about that specific page. Toggle it the same way, or type `/url`.
