**Library** is where Sparkian keeps the reusable things you create or upload, so you're not starting from scratch in every chat. You can open it from the sidebar.

<Frame caption="Library">
  <img src="https://cdn.sparkian.com/docs/sparkian-library.png" alt="Library"/>
</Frame>

It has two tabs:
- **[Knowledge base](/knowledge-base)** — files, text notes, and folders you can reference in any chat
- **[Artifacts](/canvas)** — documents, code, and other content created in Canvas during AI chat

Both tabs support search and filters, and show how much storage or how many items you're using against your [plan](/plans)'s limits.
